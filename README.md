Piezoelectric Energy Harvesting System
This project explores the generation of sustainable energy using piezoelectric sensors and vibration-based mechanical stress.

Key Features & Skills Demonstrated:

Hardware Design: Designing circuits to capture, rectify, and store voltage generated from piezoelectric transducers.

Power Electronics: Understanding power optimization, energy conversion, and voltage measurement.

Data Analysis: Monitoring and recording voltage outputs under various physical stress conditions.
